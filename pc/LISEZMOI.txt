HDJ — Hôpital de jour · Biothérapies
Hôpital d'Enfants Abderrahim El Harouchi — CHU Ibn Rochd, Casablanca
Unité de Gastro-entérologie, Hépatologie et Nutrition Pédiatrique
Installation et utilisation sur un PC Windows (sans Internet, sans serveur)
==========================================================================


1. QU'EST-CE QUE HDJ ?
----------------------
  HDJ est l'application de gestion des biothérapies de l'hôpital de jour :
  dossiers patients, protocoles par cycles, planning des fauteuils, séances
  et contrôles, bilans, carnets et documents à imprimer.

  - C'est une application web LOCALE : elle fonctionne entièrement sur ce
    PC, sans serveur et sans Internet. Rien n'est envoyé à l'extérieur.
  - Elle s'ouvre dans sa propre fenêtre (icône HDJ, sans barre d'adresse ni
    onglets) grâce au moteur de Microsoft Edge, déjà présent sous Windows 10
    et 11, ou de Google Chrome, utilisé en « mode application ».
  - Il faut : un PC Windows 10 ou 11 (4 Go de mémoire suffisent) avec
    Microsoft Edge ou Google Chrome. Aucun droit administrateur n'est
    nécessaire, rien n'est installé dans Windows.

  Contenu du dossier HDJ :
    HDJ.bat             lance l'application (cible de l'icône HDJ)
    Installer.bat       crée l'icône HDJ sur le Bureau et dans le menu Démarrer
    Mettre-a-jour.bat   installe une nouvelle version (voir 5)
    hdj.ico, hdj.png    icône (emblème du GST Casablanca-Settat)
    app\                l'application elle-même
    donnees\            LA BASE, créé à la première ouverture : ne jamais
                        le supprimer
  (Windows masque souvent « .bat » : HDJ.bat apparaît comme « HDJ », type
  « Fichier de commandes Windows ».)


2. INSTALLATION (5 étapes, environ 5 minutes)
---------------------------------------------
  1) Copier tout le dossier « HDJ » (celui qui contient ce fichier) sur le
     disque du PC : de préférence C:\HDJ (possible sans droits
     administrateur), sinon dans Documents, si ce dossier n'est pas
     synchronisé par OneDrive.
     Vous avez reçu HDJ-PC.zip : clic droit sur le fichier > Propriétés >
     cocher « Débloquer » s'il apparaît (en bas) > OK ; puis clic droit >
     « Extraire tout… », et copier le dossier HDJ obtenu dans C:\ (il
     devient C:\HDJ, chemin sans accent). Ne pas travailler depuis la clé
     USB, Téléchargements, ni l'intérieur du zip.

  2) Ouvrir C:\HDJ et double-cliquer sur Installer.bat.
     Si Windows affiche « Windows a protégé votre ordinateur » : cliquer
     « Informations complémentaires », puis « Exécuter quand même ».
     Si plusieurs personnes ont chacune leur compte Windows sur ce PC :
     chaque compte Windows lance Installer.bat une fois (l'icône est créée
     pour le compte ouvert ; la base, dans C:\HDJ\donnees, reste commune).

  3) L'icône « HDJ » (emblème du GST Casablanca-Settat) apparaît sur le
     Bureau et dans le menu Démarrer. C'est toujours par elle qu'on ouvre HDJ.

  4) Première ouverture : double-cliquer sur l'icône HDJ. La fenêtre
     s'ouvre sur l'écran de connexion (logo et nom de l'établissement).
     Au départ, la base contient des patients FICTIFS de démonstration :
       - pour reprendre une base existante : se connecter avec le code
         CHEF01, ouvrir Paramètres (roue dentée en haut à droite) >
         « Importer un fichier », choisir le fichier de sauvegarde (.json,
         obtenu dans l'ancienne installation ou sur le lien : Paramètres >
         « Exporter la base »), mode « Remplacer toute la base », puis se
         reconnecter avec son propre code ;
       - pour partir de zéro : cliquer « Démarrer avec une base vide » sur
         l'écran de connexion. Un nouveau code d'accès complet s'affiche
         une seule fois : le noter.
     Vérifier ensuite (1 minute) : fermer la fenêtre HDJ, la rouvrir par
     l'icône, se reconnecter : les patients importés (ou, pour une base
     vide, le nouveau code) doivent toujours être là. Sinon, le navigateur
     efface ses données à la fermeture (réglage du service informatique) :
     ne pas utiliser HDJ sur ce PC, prévenir l'informatique.

  5) Avec un accès complet, régler une fois pour toutes :
       - Équipe & codes (menu de gauche) : un code d'accès personnel par
         personne (accès complet ou accès hôpital de jour) ; désactiver les
         codes qui ne servent pas ;
       - Paramètres > Établissement : chef de service, téléphone de l'HDJ
         et des urgences (imprimés sur les carnets des patients) ;
       - Paramètres > Capacité de l'hôpital de jour : fauteuils, horaires,
         jours d'ouverture, puis cliquer « Enregistrer » (sous le cadre
         Établissement) ;
       - Paramètres > Sauvegarde automatique sur le disque : choisir le
         dossier de sauvegarde (voir 4).


3. UTILISATION AU QUOTIDIEN
---------------------------
  - Ouvrir HDJ par l'icône du Bureau (toujours la même) et entrer son code
    personnel. Se déconnecter en quittant le poste (en haut à droite).
  - Chaque saisie est enregistrée dès qu'on la valide (bouton
    « Enregistrer », « Valider »…), sans fichier à gérer. Un formulaire
    non validé est perdu si l'on change de page ou ferme la fenêtre.
  - Tableau de bord : séances et contrôles du jour et de la semaine,
    retards et alertes. Planning HDJ : mois, journée, semaine et feuille de
    planning à imprimer. Patients : dossier, séances, surveillance, bilan,
    notes, carnets, compte rendu.
  - Imprimer : le bouton Imprimer ouvre la fenêtre d'impression du
    navigateur (imprimante du service, ou « Enregistrer au format PDF »).
    Télécharger enregistre le document dans Téléchargements (fichier .html
    autonome, qui s'ouvre et s'imprime sans Internet).
  - Dans la fenêtre d'impression d'Edge : Plus de paramètres > décocher
    « En-têtes et pieds de page » (une seule fois, le réglage est
    mémorisé) et garder Marges : Par défaut.
  - Carnet patient (français / arabe) : choisir « Vue A4 recto-verso »
    (A4 paysage, retournement sur le bord court, puis plier en deux) sauf
    si l'imprimante a du papier A5 (alors recto verso sur le bord long) ;
    faire un essai sur une feuille.
  - Edge 131 ou plus récent est conseillé pour que les numéros de page et
    l'identité du patient s'impriment sur les pages suivantes ; Edge 87
    minimum. Vérifier la version dans edge://version (chrome://version
    pour Chrome).


4. SAUVEGARDES — OÙ SONT LES DONNÉES
------------------------------------
  Où sont les données ?
  - Dans le dossier « donnees » du dossier HDJ (par exemple
    C:\HDJ\donnees), sur le disque de ce PC. C'est le profil du navigateur
    utilisé par HDJ : il ne se lit pas à la main. Ne jamais le supprimer,
    ni le déplacer pendant que HDJ est ouvert.
  - Les données sont liées à CE dossier HDJ et au navigateur avec lequel
    HDJ a été ouvert la première fois (Edge ou Chrome, noté dans
    donnees\navigateur.txt).

  Mettre en place dès le premier jour :
  1) Sauvegarde automatique sur le disque (Paramètres) : « Choisir le
     dossier de sauvegarde… », par exemple C:\HDJ-sauvegardes, un dossier
     réseau du service ou une clé USB laissée branchée. HDJ y écrit
     lui-même la base après chaque modification (ryze-base.json) et une
     copie datée par jour (ryze-sauvegarde-AAAA-MM-JJ.json).
     À chaque réouverture de HDJ (pas seulement après un redémarrage),
     l'autorisation d'écrire est redemandée à la connexion : cliquer
     « Autoriser » (ou « Autoriser à chaque visite » si proposé), sinon
     Paramètres > « Réactiver (autoriser l'écriture) ». Tant que personne
     n'a cliqué, la sauvegarde automatique est arrêtée et une alerte
     l'indique sur le tableau de bord.
     Sécurités : avant tout remplacement de la base (import en mode
     « Remplacer toute la base », par exemple), HDJ écrit d'abord dans ce
     dossier une copie de la base actuelle, « ryze-avant-… », qui peut se
     réimporter comme une sauvegarde. Les copies datées récentes sont
     toutes gardées ; au-delà, HDJ ne garde que la plus ancienne copie de
     chaque mois. Une alerte apparaît si la clé ou le dossier de
     sauvegarde est introuvable (clé USB retirée, par exemple).
  2) Export, chaque semaine et avant toute mise à jour : Paramètres >
     « Exporter la base » enregistre ryze-sauvegarde-AAAA-MM-JJ.json dans
     Téléchargements. Copier ce fichier sur une clé USB rangée ailleurs.
  3) Restaurer : Paramètres > « Importer un fichier » > choisir le fichier
     .json > « Remplacer toute la base ».


5. MISE À JOUR
--------------
  Avant tout : Paramètres > « Exporter la base » (voir 4).

  Méthode simple (recommandée) :
  1) Débloquer le nouveau HDJ-PC.zip (Propriétés, comme en 2, étape 1),
     puis le décompresser sur la clé USB (ou ailleurs, mais PAS dans le
     dossier HDJ installé).
  2) Fermer HDJ.
  3) Dans le NOUVEAU dossier HDJ, double-cliquer sur Mettre-a-jour.bat.
     Il retrouve le dossier HDJ installé (noté par Installer.bat) ou le
     demande (faire glisser le dossier dans la fenêtre), puis :
       - renomme l'ancien dossier app en app-ancien-AAAAMMJJ (copie de
         sauvegarde) ;
       - met le nouveau dossier app à sa place ;
       - ne touche JAMAIS au dossier donnees : la base est conservée ;
       - affiche ce qu'il a fait.
  4) Rouvrir HDJ par l'icône du Bureau et vérifier ses patients. Les
     dossiers app-ancien-… peuvent être supprimés après quelques jours.

  Méthode manuelle : HDJ fermé, renommer C:\HDJ\app en app-ancien, puis
  copier le nouveau dossier app à sa place. Ne jamais remplacer, déplacer
  ni supprimer le dossier donnees.

  Revenir à la version précédente : HDJ fermé, supprimer app et renommer
  app-ancien-AAAAMMJJ en app. Si la nouvelle version a déjà mis la base à
  niveau, l'ancienne peut refuser de l'ouvrir : cliquer « Continuer avec
  une base neuve », se connecter avec CHEF01, puis importer l'export fait
  avant la mise à jour (Paramètres > « Importer un fichier » >
  « Remplacer toute la base »).


6. PROBLÈMES FRÉQUENTS
----------------------
  - « Ni Microsoft Edge ni Google Chrome n'ont été trouvés » : Edge est
    normalement fourni avec Windows 10 et 11. S'il a été retiré, installer
    Microsoft Edge ou Google Chrome (service informatique), puis relancer
    HDJ.

  - L'icône HDJ n'apparaît pas sur le Bureau, ou elle est blanche :
    relancer Installer.bat depuis le dossier HDJ (hdj.ico doit se trouver
    à côté). Si le dossier HDJ a été déplacé, relancer Installer.bat
    depuis le nouvel emplacement. En attendant, double-cliquer sur
    HDJ.bat. Windows met parfois quelques minutes à afficher une icône.

  - Les données ont « disparu » (base vide, ou patients de démonstration) :
    elles n'ont pas disparu, HDJ a été ouvert autrement que d'habitude :
      . dans un autre navigateur, ou en double-cliquant sur
        app\index.html au lieu de l'icône HDJ ;
      . depuis un autre dossier HDJ (copie restée sur la clé USB, ancienne
        copie, dossier déplacé) : les données suivent le dossier donnees.
    Fermer cette fenêtre et rouvrir HDJ par l'icône du Bureau. Sinon,
    importer la dernière sauvegarde (Paramètres > Importer un fichier).

  - Impression en couleur ou en noir et blanc : Paramètres > Impression
    (accès complet). Le réglage vaut pour tous les documents imprimés et
    téléchargés ; le nombre de pages ne change pas.

  - « Windows a protégé votre ordinateur » au lancement d'un fichier .bat :
    « Informations complémentaires » > « Exécuter quand même ». Cela arrive
    pour des fichiers venus d'un zip téléchargé ; Installer.bat débloque
    ensuite les fichiers du dossier HDJ.

  - Le PC est remplacé : installer HDJ sur le nouveau PC (étapes 1 à 3),
    puis importer la dernière sauvegarde (Paramètres > Importer un fichier).
